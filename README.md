# Adfix — Meta Ads Checklist

A simple one-page checklist for reviewing a Meta ad before publishing it. It covers the creative, ad copy, destination link, budget and schedule, and audience.

- **Page:** `index.html` (single file, no framework)
- **Hosting:** Cloudflare Pages, deployed automatically from the `main` branch
- **Access:** Restricted with Cloudflare Access to `@adfix.com` email addresses (One-time PIN)

Created by Nicholas David.
